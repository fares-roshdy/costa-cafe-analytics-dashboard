# Costa Cafe Analytics Dashboard (Power BI)

An interactive Power BI dashboard for a cafe business, tracking orders, payment methods and shift performance.

## Overview

Built an end-to-end sales dashboard over a real cafe dataset: **1,313 orders** and **EGP 426,275** in sales. The dashboard lets a manager see what sells, when it sells, and how each shift performs.

## Tech

- Power BI
- Power Query (data cleaning and shaping)
- DAX (measures and KPIs)

## What the dashboard answers

- **Order tracking** across the full dataset of 1,313 orders
- **Payment-method analysis**: how customers actually pay
- **Shift performance**: which shifts drive the most revenue
